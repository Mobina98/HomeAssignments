## Description

Create a hierarchy of elite_units with overload constructor and operators.
This assignment builds another C++ OOP project(Object-Oriented Programming), extending the idea of unit-based roles but focusing on interaction and behavior between different unit types.
It emphasizes class design, function documentation, and modular structure, while keeping consistent naming conventions for clarity.
The project demonstrates practical use of separate compilation, abstraction, and role-based unit logic in a structured C++ application.
