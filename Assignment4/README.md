## Description

Create a hierarchy of elite_units with overload constructor and operators.
This assignment implements a C++ object-oriented design for a game-like simulation where different types of units (e.g., heavy, assault, marksman, support, elite, commander) interact.
Each unit is modeled as a separate class with its own behavior and attributes, demonstrating the use of inheritance, polymorphism, and encapsulation in C++.
The project showcases class hierarchy, file modularity, and integration through a main program.
