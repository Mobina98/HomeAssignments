## Description

Creating a hierarchy of elite_units with composition association.
A C++ object-oriented programming project that simulates a combat system inspired by Transformers. 
The project demonstrates core OOP principles including class design, encapsulation, inheritance, polymorphism, and composition through a hierarchy of robotic characters with unique weapons and abilities.
